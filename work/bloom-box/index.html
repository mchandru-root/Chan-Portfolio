Splunk SIEM – Security Monitoring

Splunk
SOC
SIEM

A Security Operations Center dashboard built with Splunk to monitor, analyze, and visualize security events, authentication activity, network traffic, and potential threats in real time.

Project Overview

Built and configured a Splunk-based Security Information and Event Management (SIEM) environment to collect, monitor, search, and analyze security-related logs and events.

The project provided hands-on experience with the core workflow of a Security Operations Center (SOC), including centralized log monitoring, event analysis, alert investigation, security event correlation, and identifying potentially suspicious activity.

What I Implemented
  • Configured a Splunk environment for centralized security monitoring.
  • Collected and analyzed security-related log data using Splunk.
  • Created SPL queries to search and investigate security events.
  • Built a security monitoring dashboard using Splunk visualizations.
  • Monitored authentication and login-related activity.
  • Analyzed failed and successful login events.
  • Investigated source IP addresses associated with security events.
  • Created visualizations to identify patterns and unusual activity.
  • Used time-based analysis to investigate security events and activity.
  • Practiced a SOC-style workflow from event detection through investigation.
Security Monitoring

The Splunk dashboard was designed to provide centralized visibility into security events and help identify potentially suspicious activity.

Key areas included:

  • Authentication and login activity
  • Failed login attempts
  • Successful login activity
  • Source IP address analysis
  • Security event monitoring
  • Suspicious activity detection
  • Event frequency and activity patterns
  • Security event investigation
Event Investigation

When suspicious or unusual activity was identified, I analyzed the corresponding Splunk events and related log information to understand what occurred.

The investigation process included:

Event Detection → SPL Search → Event Analysis → IOC Identification → Investigation → Assessment

This helped me understand how SOC analysts use SIEM platforms to analyze security telemetry, investigate suspicious activity, and distinguish potentially malicious events from normal system behavior.

Splunk Dashboard

Developed a centralized security dashboard to provide a visual overview of security activity. The dashboard uses Splunk searches and visualizations to make security events easier to monitor and investigate.

The dashboard includes security metrics, event statistics, login activity, source information, and visual representations of detected events.
