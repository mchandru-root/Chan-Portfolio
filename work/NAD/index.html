Project Overview

Built and hosted a web-based Network Anomaly Detection platform designed to analyze .pcap network capture files and identify unusual or potentially suspicious network traffic patterns.

The platform allows users to upload captured network traffic in PCAP format and analyze the contents through a web-based interface. The system processes the captured traffic and extracts relevant network information for security analysis.

This project provided hands-on experience with network traffic analysis, PCAP file processing, anomaly detection, and security-focused network investigation.

What I Implemented
  • Developed a web-based interface for network traffic analysis.
  • Implemented .pcap file upload functionality.
  • Processed uploaded PCAP files for network traffic analysis.
  • Extracted relevant information from captured network traffic.
  • Analyzed source and destination IP addresses.
  • Analyzed source and destination ports and network protocols.
  • Identified unusual network communication patterns.
  • Presented analysis results through the web interface.
  • Hosted the application for practical testing and demonstration.
PCAP File Analysis

PCAP files contain captured network packets that can be analyzed to understand communication between systems. In this project, PCAP files are used as the primary input for network traffic analysis.

After a PCAP file is uploaded, the application processes the captured traffic and extracts relevant information for further analysis.

The extracted information can be used to understand network communication, identify unusual behavior, and investigate traffic patterns that may require further attention.

Network Traffic Analysis

The platform analyzes captured network traffic to understand how systems communicate and to identify patterns that differ from expected network behavior.

Key analysis areas include:

  • Source IP addresses
  • Destination IP addresses
  • Source and destination ports
  • Network protocols
  • Packet activity
  • Connection patterns
  • Traffic frequency
  • Unusual communication behavior
Anomaly Detection

The system analyzes network traffic characteristics to identify unusual patterns that may indicate anomalous network behavior.

Potential anomalies may include unusual connection attempts, repeated communication activity, unexpected ports or protocols, abnormal traffic patterns, and unexpected communication between network endpoints.

Detected anomalies are treated as indicators requiring further investigation rather than automatically being classified as confirmed malicious activity.

Network Investigation

When unusual activity is identified, the captured traffic can be examined to understand the source, destination, protocol, timing, and characteristics of the communication.

The investigation process focuses on understanding what happened, which systems were involved, when the activity occurred, and whether the observed behavior requires further security analysis.

The overall workflow followed:

PCAP Upload → Traffic Processing → Feature Extraction → Anomaly Detection → Result Analysis → Investigation

Web-Based Analysis Platform

The project was developed as a web-based security analysis platform, allowing users to upload PCAP files and analyze network traffic through a centralized interface.

Hosting the application makes it possible to demonstrate the analysis workflow using captured network traffic without requiring users to manually inspect every packet individually.
